## Следующий этап

Для постоянного обновления нужен ограниченный токен Actions read/write только этого репозитория в защищённых настройках `SCHEDULER_GITHUB_TOKEN` и отдельное разрешение на публикацию Worker-планировщика/включение Cron. В чат токен не передавать. До этого нельзя обещать актуальное расписание каждые десять минут. Включение таймера также требует успешной приёмки, включая решение ограничения дальней БЖД; текущий ready=false этому не соответствует.

Для дальней БЖД нужно дождаться снятия ограничения либо согласовать разрешённую интеграцию с источником. Не менять IP/браузер/авторизацию и не решать CAPTCHA ради обхода. Успешные локальные 54/54 более раннего запуска не доказывают текущую доступность из GitHub Actions и не подменяют проверку production.

## Ограничения

Постоянный планировщик не публиковался, Cron не включался, `SCHEDULER_GITHUB_TOKEN` отсутствует по проверенному резерву. Однократное восстановление не обеспечивает постоянную свежесть. Без отдельного согласованного этапа обновление цены/мест прекращается, старые значения должны становиться неизвестными; расписание может показываться как последнее известное в пределах семи дней.

Дальние окна некоторых источников ограничены. Полный охват регулярных автобусов, приёмка из Беларуси, фактические месячные квоты, семидневная доступность и доставка уведомлений не доказаны.
